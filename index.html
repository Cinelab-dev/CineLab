Installer CinéLabs

Une minute, sans rien d'autre à installer et sans droits d'administrateur.

  1. Téléchargez l'installateur

    Le fichier CineLabs-Installation-(version).exe, sur la page de téléchargement.

  2. Lancez-le

    Choisissez où ranger vos projets (par défaut, Documents\CinéLabs), puis cliquez sur Installer.

  3. Ouvrez CinéLabs

    Depuis le bureau ou le menu Démarrer. Le scénario d'exemple permet de tout essayer.

Windows affiche « Windows a protégé votre ordinateur » ? C'est normal pour un logiciel indépendant qui débute : cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Une version Mac arrive

CinéLabs fonctionne pour l'instant sur Windows. La version Mac est en préparation. Écrivez-nous pour être prévenu de sa sortie, ou pour nous aider à la tester.
